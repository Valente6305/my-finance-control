Privacy Policy

Effective: 10 October 2026

My Finance Control is a personal finance tracking web application operated for personal use. This notice describes the currently published application, not proposed future banking integrations.

Data stored on your device

The current app lets you enter balances, salary, debts, budgets, goals, and transactions. It stores these entries in your browser's local storage on the device where you use the app. The app does not currently transmit those entries to an application server or connect to your bank accounts.

Hosting

The website's static files are served by GitHub Pages. GitHub may process technical access information such as IP addresses and request logs according to GitHub's own privacy practices. The app itself does not operate an analytics service.

Backups

You may export financial records to a JSON file or CSV. You control where those files are stored and shared. Do not upload exported financial backups to a public repository.

Security and limitations

Browser local storage is not an encrypted financial vault. People with access to your unlocked device or browser profile may be able to access stored entries. Clearing site data, changing devices, or uninstalling the app may delete entries. Keep private backups in a protected location. Do not enter banking credentials or private API keys into this app.

Future connections

Automatic bank synchronisation is not active. Any future read-only banking feature will require a separate security and privacy review, explicit user authorisation, and an updated privacy notice before activation.

Changes

This page will be updated when material changes to data processing are introduced. You may stop using the app and delete its local browser data at any time.
